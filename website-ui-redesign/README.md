# 🖥️ Website UI Redesign — Rosemary & Rye Bakery

**A UI/UX case study: taking an existing, usability-poor small-business website through heuristic evaluation, mood boarding, style guide creation, and a high-fidelity, responsive redesign.**

> Task type: UI/UX Design exercise
> Deliverables: heuristic evaluation → mood board & style guide → high-fidelity mockups (desktop + mobile)

---

## 🎯 The Brief

Redesign the interface of an existing website to improve usability by:

1. Performing a heuristic evaluation to identify usability issues
2. Creating a mood board and style guide
3. Designing high-fidelity mockups
4. Ensuring responsive layouts for desktop and mobile

**Chosen site: Rosemary & Rye**, a neighborhood bakery & café. Its current website is a typical small-business site built years ago and never revisited: a cluttered nav, low-contrast body text, no responsive behavior, and a buried call-to-action. It's a realistic, low-stakes subject that still has enough real usability problems to make the evaluation meaningful.

## 🖼️ Viewing the Mockup

`homepage-redesign.html` is a single self-contained file — open it directly in any browser, or resize the window (or use your browser's device toolbar) to see the responsive behavior: the nav collapses to a full-screen menu and the layout re-stacks below 720px width.

## ✅ Expected Outcome

By the end of this repo you should be able to see, end to end:
- How a heuristic evaluation turns vague "this site feels dated" impressions into specific, prioritized problems
- How a mood board and style guide translate research findings into concrete visual decisions (not just "make it modern")
- How visual hierarchy and layout choices in the mockup directly fix the issues found in the evaluation
- How the same layout adapts, rather than just shrinks, from desktop to mobile
